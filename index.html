backend developer & systems programmer. I write things in Rust and Kotlin that are meant to run close to the hardware for a long time.

right now I'm building kosh — a self-hostable personal storage platform where the server is a dumb bucket of bits. client-side AES-GCM, ECDH device pairing over ephemeral X25519, WebAuthn passkeys backed by a BIP-39 recovery phrase, mDNS zero-config, and a storage engine tuned for spinning rust on a 2011 Sandy Bridge box. the server never sees a filename, a MIME type, or a byte of plaintext. that's the whole point.

before that, I wrote a BitTorrent client from scratch (qbit-tui) — raw tracker UDP negotiation, peer handshake, piece management, state persistence. it's archived now. it taught me more than any tutorial could.
